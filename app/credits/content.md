# Inspiration

This website design is inspired by [Sarthak Rawat's Sketchbook UI Components](https://sarthakrawat-1.github.io/sketchbook-ui/), though it's made without looking at any of its source code.

# Tools & Frameworks

[Next.js](https://nextjs.org), [Tailwind CSS](http://tailwindcss.com/) and [React Markdown](https://github.com/remarkjs/react-markdown) for making the entire website, [Cloudflare](https://www.cloudflare.com/) for hosting it entirely for free, [is-a.dev](https://is-a.dev) for the nice subdomain, and [GitHub](https://github.com) for hosting the source code of this site for free as well.

# Fonts

[Caveat Brush](https://fonts.google.com/specimen/Caveat+Brush) for heading texts.

[Patrick Hand](https://fonts.google.com/specimen/Patrick+Hand) for body/long content.

[Fira Code](https://fonts.google.com/specimen/Fira+Code) for code blocks.
